# k-takip-winforms

Refactored a legacy C# WinForms personnel tracking application originally developed as a school project, focusing on security, database improvements, and clean code practices.



This project was originally developed two years ago as a school assignment.

I later revisited the codebase and treated it as a legacy application, refactoring it to improve security, structure, and maintainability.



During the refactoring process:



Database connection logic was fixed and centralized



Password handling was improved by implementing SHA-256 hashing



Code was cleaned up and reorganized to follow better practices



A UI redesign and improvements are planned for future updates.
